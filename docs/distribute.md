# Распространение (без магазинов)

Клиент раздаётся напрямую — вам и друзьям. Аккаунтов нет: каждому выдаётся
**персональная подписка** с сервера ([VPN-Server](../../VPN-Server)) и файл
приложения.

## Канал распространения

1. **GitHub Releases** (основной). В репозитории создаётся релиз по тегу, к нему
   прикладываются:
   - `vpn-client-windows.zip`
   - `app-release.apk`
   - `SHA256SUMS`
2. Друзьям отправляется **ссылка на релиз** и его/её персональная подписка.

> Почта как канал — только запасной: `.exe`/`.apk` часто режут почтовые фильтры
> (тип/размер), а антивирусы насторожатся на неподписанный файл. Ссылка на
> GitHub Release надёжнее.

## Что выдаётся каждому другу

| Что | Откуда |
|---|---|
| Персональная подписка (`subscription.txt` или QR) | сервер: `clients/<имя>/` |
| Приложение | ссылка на GitHub Release |

Нельзя давать один профиль на несколько человек — это общий пароль доступа.
Администратор создаёт отдельного пользователя на устройство
(`vpn-user.sh add <имя>`).

## Windows

1. Скачать `vpn-client-windows.zip`, распаковать.
2. Запустить `vpn-client.exe`. При первом запуске Windows покажет **SmartScreen**
   (файл не подписан авторитетным сертификатом): «Подробнее» → «Выполнить в любом
   случае». Это ожидаемо без платной подписи кода.
3. Вставить подписку (или отсканировать QR со телефона) и нажать «Подключить».

Опционально: подписать exe сертификатом (Authenticode), чтобы убрать
предупреждение — ~$100–400/год. Без магазина не обязательно.

## Android

1. Скачать `app-release.apk` на телефон.
2. Разрешить установку из неизвестных источников (для файлового менеджера/
   браузера). Play Protect может предупредить — «Всё равно установить».
3. Открыть приложение, вставить подписку или отсканировать QR, нажать
   «Подключить».

APK подписывается собственным keystore — для sideload этого достаточно, Google
Play не нужен.

## Проверка целостности

Рядом с релизом лежит `SHA256SUMS`. Проверка:

```powershell
# Windows
Get-FileHash .\vpn-client-windows.zip -Algorithm SHA256
```

```bash
# Linux/macOS
sha256sum -c SHA256SUMS
```

## Безопасность раздачи

- Подписка = доступ к VPN. Не публиковать её в открытых чатах и репозиториях.
- Файлы приложения можно публиковать (секретов внутри нет).
- Если подписка утекла — администратор меняет ключ:
  `sudo ./scripts/vpn-user.sh rotate <имя>`, и старая ссылка умирает.
